# 小组项目导航 Demo 测试指引

本项目供课程演示与软件测试使用。测试时请使用虚构数据，不要录入真实密码、个人账号或私人资料。

## 演示环境账号

当前共享演示环境的后台账号为 `admin`，密码为 `admin123.`。登录页也会显示这组账号。

从仓库新安装的环境没有默认管理员账号：首次访问后台会进入安装向导，由部署者创建账号；新环境的账号可能与共享演示环境不同。

## 推荐测试流程

| 模块 | 可以测试 | 注意事项 |
|---|---|---|
| 首页导航 | 默认小组协作分类、切换分类、站内搜索、搜索引擎、语言和主题 | 访问资源会增加点击统计 |
| 链接与分类 | 新增、编辑、排序、启停和删除 | 使用带“测试”字样的虚构条目；操作会影响共享数据 |
| 统计 | 查看总点击量、分类和链接排行 | 测试数据会改变统计结果 |
| 账号密码 | 验证当前密码、长度、确认密码不匹配、成功改密 | 改密会立刻更换共享后台密码；使用“恢复完整演示环境”可恢复 `admin / admin123.` |
| 密码保险箱 | 使用主密码 `12345678` 解锁，填入测试样例、保存、显示 / 复制、编辑、搜索、删除、锁定和重新解锁 | 只使用虚构凭据。恢复完整演示会清空保险箱全部条目并重新设置该主密码 |
| 重置演示 | 重置链接、清空为空白、恢复完整 Demo | 完整恢复会先自动备份，然后删除所有后台账号并重建 `admin / admin123.`，恢复 4 个分类、100 条链接、清空点击统计与保险箱；网站文案和联系邮箱保留。其他成员需重新登录 |

### 恢复共享演示环境

进入后台「重置演示」，选择“恢复完整演示环境”，勾选确认并输入页面指定短语。系统会先成功备份数据库，再清除原保险箱条目、恢复公开账号和演示链接。备份快照保存在 `data/backups/`，如要找回恢复前的数据，需要管理员手动恢复该 SQLite 备份。网站文案、主题、搜索配置和联系邮箱保留。

如果不想影响共享展示数据，请先复制项目和数据库到单独目录，并使用单独端口运行，再测试成功改密或破坏性操作。

## 密码保险箱测试样例

“填入测试样例”按钮只会向表单填入虚构的 `example.com` 登录数据，不会自动写入数据库。点击“加入保险箱”后才会保存并加密。保存后可验证：

1. 默认密码打码，点击“显示”后能够读取，再点一次会隐藏；
2. 点击“复制”后可粘贴样例密码；
3. 编辑、搜索、分类筛选和删除只作用于对应条目；
4. 手动锁定后，需重新输入保险箱主密码；空闲 15 分钟也会自动锁定。
