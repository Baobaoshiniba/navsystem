# A 方案：简洁资源工作台

设计北极星：让小组成员在一个清楚、安静的工作台里找到资源，管理员能在同一套界面中维护它。

采用柔和暖灰米白、深灰与单一蓝色，保留深色模式；浅色底使用稀疏低对比的几何散点，深色底使用更暗的对应图形；系统字体优先，不依赖在线字体。首页首屏以居中的搜索工具为主操作，搜索框下紧接每日一言；品牌栏保留识别，分类筛选和资源网格从首屏往下排列。每日一言通过同源 PHP 端点中文使用 Hitokoto 哲学类语句与英文 ZenQuotes 每日励志语，按吉隆坡日期缓存，并提供本地文案兜底。后台采用固定侧边导航，手机变为可横向滚动的栏目导航。

所有通用操作使用本地 24px / 1.9px 描边 SVG；网站使用本地品牌标志或网站缓存图标，失败时回退中性字母徽章。可编辑的原始图标字段与数据不删除。只让资源卡片有边框，不再给分类套大卡片。

首页搜索为主操作，分类为次操作；语言、主题和后台入口保留。按钮提供按下反馈、分类切换提供短过渡、首屏轻微出场，并尊重减少动态效果设置。去除网格、渐变字、光斑、玻璃和重阴影；后续按反馈将刺眼冷白改为暖灰米白，并加上轻量的几何散点背景。

本轮沿用现有功能与双语言，不重置数据，不引入界面框架或外部运行依赖。

## 实现与验收

- 主界面、后台共用导航、登录/注册、设置、分类、统计、重置与保险箱统一采用 A 方案。手机端新增表单默认折叠，编辑状态保持展开，键盘 Enter 可展开/收起；折叠不会清空输入。
- 独立静态视觉评审 1 轮，8/10。按反馈修正了保险箱眼睛 Emoji、后台统计区过重、登录页宣传区抢焦点。修正后由主执行者复核；没有把静态评审当成功能验证。
- 删除了顶栏重复的欢迎语和统计胶囊、登录页宣传段落的展示、分类外层大卡片、网格背景、光斑与重阴影。保留必要的站点介绍、分类、资源说明和状态。
- 动效保留短出场、按钮按下反馈与分类切换 170ms 过渡；减少动态效果模式下禁用。工具页不加入营销滚动叙事，截图工具的滚动提示因此不处理。
- PHP 语法检查、双语言迁移/回退检查、语言切换检查通过；隔离副本 16 个中英文页面及保存读回、CSRF、JavaScript 语法检查通过。
- 实际浏览器验证：分类筛选、搜索引擎切换、空搜索提示、中英文切换保留分类、主题切换、资源点击计数即时更新且刷新后读回、表单键盘展开/折叠后输入保留。
- 已检查 1440×900、390×844 的首页、后台和登录页；补查深色中文首页、站点设置及保险箱。表格在自身容器内横向滚动，不让操作列互相遮盖。未执行生产部署和外部图标批量抓取。
- 验收过程只使用 /tmp 隔离数据库，用户本地数据没有重置。网站标志的来源和许可见 assets/brands/SOURCES.md。

## 视觉微调：柔和背景

针对浅色冷白过亮的反馈，将背景调整为暖灰米白，卡片由纯白改为柔和的近白色，蓝色仍作为唯一操作强调色。浅色和深色主题分别使用本地 SVG 几何散点，图形以错落的圆、三角形、菱形和六边形组成，低对比、静态、不遮挡内容。预览检查了首页浅色与深色两种状态；新素材无需网络请求。

## 品牌图标微调

将通用的四宫格加号替换为自绘方向罗盘标记，favicon 与页头共用同一图形；统计卡改用语义区分的点击指针、均值线和峰值趋势图标，移除手势 emoji。通用 SVG 描边统一为 1.9px 并使用主题强调色。只保留品牌 hover 的轻微偏转，未引入 GSAP 运行时依赖；这次没有需要编排的动画流程。

## 首页方向调整：工具启动台

反馈显示，带有首屏介绍、分组标题和较大资源网格的页面更像目录展示，不够像快速启动工具。首页调整为紧凑标题与站内实时搜索、横向分类切换、单一资源网格。搜索输入实时匹配名称、网址、描述和分类；提交按钮清楚标为网页搜索，仍可将关键词交给选定的搜索引擎。桌面使用四列网格、中屏三列、手机双列；入口弱化卡片边框和描述，突出图标、名称与网址，分类作为辅助信息。背景几何降低对比，避免压住入口。切换分类不再滚动页面，分类和搜索可组合使用。

## 首页首屏：搜索与每日一言

首页打开后先显示搜索引擎选择与大尺寸搜索栏，其下为每日寄语；品牌已由顶部工作台标识承担，不再重复放置大标题。寄语按吉隆坡本地日期通过同源端点获取 中文通过 Hitokoto、英文通过 ZenQuotes 获取每日语句，SQLite 按语言和吉隆坡日期分别缓存并保留出处链接；接口不可用时显示本地双语原创寄语。搜索面板维持中性色，蓝色只用于提交按钮和焦点状态。
