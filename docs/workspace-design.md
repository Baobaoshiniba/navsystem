# A 方案：简洁资源工作台

设计北极星：让小组成员在一个清楚、安静的工作台里找到资源，管理员能在同一套界面中维护它。

采用冷白、深灰与单一蓝色，保留深色模式；系统字体优先，不依赖在线字体。首页采用品牌栏、紧凑介绍/搜索区、分类筛选和资源网格；统计退至资源区的文字摘要。后台采用固定侧边导航，手机变为可横向滚动的栏目导航。

所有通用操作使用本地 24px / 1.7px 描边 SVG；网站使用本地品牌标志或网站缓存图标，失败时回退中性字母徽章。可编辑的原始图标字段与数据不删除。只让资源卡片有边框，不再给分类套大卡片。

首页搜索为主操作，分类为次操作；语言、主题和后台入口保留。按钮提供按下反馈、分类切换提供短过渡、首屏轻微出场，并尊重减少动态效果设置。去除网格、渐变字、光斑、玻璃和重阴影。

本轮沿用现有功能与双语言，不重置数据，不引入界面框架或外部运行依赖。

## 实现与验收

- 主界面、后台共用导航、登录/注册、设置、分类、统计、重置与保险箱统一采用 A 方案。手机端新增表单默认折叠，编辑状态保持展开，键盘 Enter 可展开/收起；折叠不会清空输入。
- 独立静态视觉评审 1 轮，8/10。按反馈修正了保险箱眼睛 Emoji、后台统计区过重、登录页宣传区抢焦点。修正后由主执行者复核；没有把静态评审当成功能验证。
- 删除了顶栏重复的欢迎语和统计胶囊、登录页宣传段落的展示、分类外层大卡片、网格背景、光斑与重阴影。保留必要的站点介绍、分类、资源说明和状态。
- 动效保留短出场、按钮按下反馈与分类切换 170ms 过渡；减少动态效果模式下禁用。工具页不加入营销滚动叙事，截图工具的滚动提示因此不处理。
- PHP 语法检查、双语言迁移/回退检查、语言切换检查通过；隔离副本 16 个中英文页面及保存读回、CSRF、JavaScript 语法检查通过。
- 实际浏览器验证：分类筛选、搜索引擎切换、空搜索提示、中英文切换保留分类、主题切换、资源点击计数即时更新且刷新后读回、表单键盘展开/折叠后输入保留。
- 已检查 1440×900、390×844 的首页、后台和登录页；补查深色中文首页、站点设置及保险箱。表格在自身容器内横向滚动，不让操作列互相遮盖。未执行生产部署和外部图标批量抓取。
- 验收过程只使用 /tmp 隔离数据库，用户本地数据没有重置。网站标志的来源和许可见 assets/brands/SOURCES.md。
