# 中英文双语言设计

## 目标与范围
沿用现有深浅色、玻璃卡片与导航布局，让中文与英文用户都能完成查找资源、搜索与后台管理。覆盖简体中文（zh-CN）和 English（en）；本方案已实现，并扩展为小组作业 Demo；验证记录见 verification.md。

## 语言入口与交互
- 首页、后台公共顶栏与登录/注册页统一提供「中文 | English」，放在主题按钮旁；当前语言高亮，键盘可操作，读屏能获知选中状态。不使用国旗表示语言。
- 首次访问默认中文；显式 URL 参数 lang 优先，其次使用已保存的语言偏好，最后回退中文。只允许 zh-CN/en。
- 手动切换后用 Cookie 保存 365 天，前后台共享；刷新后保留选择。
- 浏览页面切换时保留路径、分类、查询参数及锚点，不退出登录。首页分类筛选目前会重写查询参数，实现时须改为保留 lang 等参数。
- 表单有未保存修改时，切换语言前提示保存或放弃；取消切换则保留原页面与输入。不重放 POST，不将账号、密码或保险箱内容放入 URL。
- 移动端语言入口保持可见，统计信息允许换行；英文按钮与标题按内容自适应，避免固定宽度截字。只用轻微选中态过渡，尊重减少动态效果设置。

## 两类内容分别管理
### 系统界面文案
建立统一词条：导航、按钮、表头、占位提示、验证、确认弹窗、成功/失败提示、图标抓取进度、统计、空状态、读屏标签。包括 PHP 输出、内联 JavaScript 和接口返回的用户消息，避免只翻译静态页面。

### 管理员录入内容
- 站点设置提供「中文内容 / English content」两组字段：公司名称、Logo 文字、欢迎语、搜索提示、页脚。
- 分类增加英文名称；链接增加英文标题和英文描述。URL、图标、排序、点击次数共用。
- 英文内容缺失时逐字段回退原中文；不以空白覆盖已有内容，不强制机器翻译公司与产品名。
- 保险箱中的账号、密码、备注和用户录入信息保持原样，仅翻译操作界面。
- 搜索引擎名称可以双语展示，但使用稳定标识关联同一引擎，避免切换语言改变默认选择；现有名称标识需兼容迁移。

## 实现落点
- 新增 lib/i18n.php、lang/zh-CN.php、lang/en.php：语言解析、词条与具名参数替换；参数在输出上下文中正确转义。英文缺词回退中文，未知词条在开发检查中报出。
- config.php 的 page_header 与 admin/_init.php 的 admin_header 统一输出当前 html lang、语言入口及本地化标题；登录注册页复用入口。
- 前端使用服务端安全序列化的词条，不能用全页字符串替换。计数使用本地化数字格式与英文单复数。
- settings 复用现有键值表新增 *_en；categories/links 幂等增加英文列。保留旧字段作为中文来源，兼容已有数据库，不重置演示或业务数据，不提交运行时数据库变化。
- 推荐按「公共语言层 → 首页与登录 → 站点设置和内容编辑 → 全后台与动态提示」实施；全部完成后再同步两个远端。

## 验收
- 首页、登录、注册、链接、分类、设置、统计、保险箱逐页检查两种语言，包括成功、失败、空状态与确认弹窗。
- 中文旧数据升级前后条数、URL、点击数、账号及保险箱密文保持一致；英文缺字段正常回退。
- 切换、刷新、前后台跳转保留语言；分类过滤不丢语言参数；未保存表单取消切换后输入不丢。
- 桌面与手机、深浅色、键盘操作及 200% 缩放下检查英文长文案不遮挡。
- 已完成代码和运行检查，以及首页和登录页的实际界面自检；未进行独立评审。
