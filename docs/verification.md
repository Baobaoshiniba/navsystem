# 双语言与小组作业 Demo 验证记录

## 交付范围
保持现有浅色/深色、卡片与布局，仅增加共用语言入口并适配英文长度。首页、登录、注册、链接、分类、设置、统计、重置与保险箱操作文案均接入本地词条；管理员可维护站点和导航内容的英文版本。界面语言与用户录入内容分别处理，缺失英文内容按字段回退中文。

Demo 使用「小组项目导航 / Team Resource Hub」品牌，4 个分类、12 条公开工具与资料入口，所有点击初始为 0。保险箱为空，注册默认关闭。默认演示账号为 `admin` / `demo12345`。原有公司、采购、电商、物流和内网演示地址已从初始资源中移除。

运行中的数据库和本地备份不纳入版本控制；仓库只保留 `data/demo.json`，首次启动建立 SQLite 并载入演示数据。已有使用记录不自动重置；后台的「重置演示」恢复导航演示数据，账号与站点设置按现有确认流程保留。

## 已验证
- 所有 PHP 文件语法检查。
- `php tests/i18n_smoke.php en`、`php tests/i18n_smoke.php zh-CN`：增量迁移、重复迁移、旧内容/点击保留、英文回退、站点设置、词条、参数、输出编码、查询参数与 4/12 演示内容检查通过。
- 隔离副本：16 个中英文页面渲染、语言 Cookie、非法语言回退、内联 JavaScript 语法检查通过。
- 隔离副本：分类、链接与站点中英文内容保存后读回正常，原始中文不被英文覆盖，错误 CSRF 请求不写入数据。
- `node tests/language_switch.test.js`：取消语言切换后输入保留，确认切换后保留分类参数和锚点；无修改时不弹确认。
- 独立浏览器：中英文首页和登录页；分类筛选后切换语言仍保留当前分类；英文空状态、搜索引擎名称、计数单复数与未保存表单切换提示可见。
- 首页桌面与手机截图检查通过；沿用现有渐变品牌标题。修正了回退图标渐变中的无效色值表达式与页脚文字对比度。
- 保留原有主题、卡片和页面动效，仅为语言选中态添加轻微过渡，并尊重减少动态效果设置。

## 验证边界
本轮为主执行者自检，未独立评审。没有为翻译增加外部依赖或在线翻译调用。外部资源填写公共入口；外部平台登录与可用性不属于本地功能检查。未执行外部图标批量抓取。
